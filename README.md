# ✨ Ethereal Sarees

### A Premium Luxury Saree E-Commerce Experience

**Ethereal Sarees** is a modern, elegant and fully responsive saree e-commerce website designed for showcasing and selling premium handcrafted sarees online.

The website focuses on a **luxury fashion experience**, combining refined UI design, smooth animations, responsive layouts and a complete shopping journey from product discovery to checkout.

# ⚡ Animations & Interactions

The website uses **Framer Motion** to create a smooth premium experience.

Animations include:

* Hero section animations
* Page transitions
* Product card animations
* Hover interactions
* Scroll-based animations
* Image transitions
* Button interactions
* Staggered content animations

The goal is to make the website feel more like a **premium fashion brand** rather than a traditional e-commerce store.

---

# 📱 Responsive Design

Ethereal Sarees is built with a **mobile-first responsive approach**.

The interface adapts across:

* 📱 Mobile
* 📲 Tablet
* 💻 Laptop
* 🖥️ Desktop
* 🖥️ Large screens

Special attention has been given to navigation, product grids, filters, cart and checkout layouts on smaller screens.

---

# 🧠 State Management

The project uses React-based state management for:

* 🛒 Cart
* ❤️ Wishlist
* Product interactions
* Persistent shopping data

Cart and wishlist information is stored using **LocalStorage**, allowing users to keep their selections even after refreshing the page.

# 🚀 Getting Started

Clone the repository:

```bash
git clone <your-github-repository-url>
```

Navigate to the project:

```bash
cd ethereal-sarees
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

---

# 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
